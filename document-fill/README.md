# document-fill

给一份文书模板 + 本案知识库，按模板取证填充，产出干净文书 + 溯源/缺口报告——闭世界取证、宁可查不到也不编造、缺口显性标注。

## 交付物
- 填好的文书（docx 或 markdown，取决于模板格式与运行环境）
- 溯源/缺口报告：每个待填项的取值、来源出处、状态标签，以及找不到的缺口清单

## 使用方式
本 skill 的入口是 `SKILL.md`。**整个 `document-fill/` 文件夹是交付单元**——`references/`、`scripts/` 下的内容是运行时按需读取/调用的正文，只拿走 `SKILL.md` 单个文件无法使用本 skill。
