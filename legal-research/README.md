# 法律研究与案例检索 Skill

面向**文件系统类 AI agent**（能读文件、能遍历目录：Claude Code / Codex / Cursor / Cline / Copilot CLI / Gemini CLI 等）的技能：接收一个法律问题或一组事实，经共享的检索核验层（MCP → 模型知识回退），产出**执业律师级**的法律研究报告或类案检索报告。每条命题带来源标签、过终检门、附免责声明。

> ⚠️ **交付单元是整个 `legal-research/` 文件夹，不是单个 `SKILL.md`。** SKILL.md 只是入口索引与常驻底线，正文（路由/检索核验/骨架/护栏/报告模板/终检门）在 `references/` 里，运行时由 agent 按需读取。只把 SKILL.md 一个文件交出去会导致 agent 读不到这些文件。

---

## 一、用途

| 交付物 | 触发场景 |
|---|---|
| **法律研究报告** | 论证某法律问题/争议点（"能否解除""是否有效""如何认定""论证……"） |
| **类案检索报告** | 检索类案/裁判规则（"帮我查这类纠纷怎么判""同案同判分析""裁判倾向"） |

本 skill **只做研究报告与类案检索报告**，不做合同审查、合同起草、企业核验、尽调合规、续约提醒、流程图。合同审查请用同仓库的 `contract-review`。

---

## 二、三模式

- **研究模式** —— 输入是一个法律问题。走 `00 建档 → 10 检索核验 → 20 论证骨架 → 30 护栏 → 40 研究报告 → 48 终检`。产出含八节结构的研究报告（执行摘要 / 问题与范围 / 法律框架 / 解释与学说 / 司法实践 / 要件·举证·证据 / 结论与建议 / 来源与核验）及免责声明。
- **检索模式** —— 输入是一组事实或案件类型。走 `00 → 10 → 21 类案归纳 → 41 检索报告 → 48`。产出含检索式回显、类案清单、裁判规则归纳、裁判倾向统计、个案启示、来源与核验六节的检索报告及免责声明。
- **复合模式** —— 研究问题需类案支撑。以 `20` 为主线，在"司法实践"步内嵌 `21` 子流程；报告走 `40` 并含类案清单。

边界模糊时 agent 会先一句话确认（研究 vs 检索 vs 两者），不静默选择。

---

## 三、设计要点

- **检索核验脊梁**（`references/10-retrieval-core.md`）：两级级联（MCP → 模型知识），两条正交标注轴（验证渠道 + 权威位阶），决策树式规范效力检查（七级状态 + 强制复核触发条件），查全/查准 KPI 与二次检索决策矩阵，三轮检索留痕，注入防御，前提核实。
- **分析薄护栏**（`references/30-analysis-guardrails.md`）：只装模型默认会做错/做空/不肯结构化的 delta —— 类推禁区、But-for/NESS 因果切换、目的解释禁口号、涵摄四段与木桶置信度、致命缺陷否决、证据-要件挂钩矩阵、领域陷阱清单。不重教方法。
- **终检门**（`references/48-qc-gate.md`）：报告产出前必过的唯一不可跳关卡，QC 七项（来源标签完整 / 效力核验 / 无编造 / 护栏触发核对 / 置信度门禁 / 强制核验披露 / 免责声明），不通过按精确回退目标退回补正，回退次数上限防死循环。
- **三层防幻觉防御**：硬不变量常驻 SKILL.md（底线不押在深层文件）+ 单一终检门（路径无关复核）+ `validate.py` 堵作者时结构漂移。

## 四、安装与运行

要求 **Python 3.8+**。校验与测试脚本位于 `legal-research/`，**仅用标准库，无需安装额外依赖**：

```bash
cd legal-research

# 校验 skill 结构完整性（每次修改 references/ 后运行）
python validate.py
# 预期：✅ 通过（0 条软警告）

# 运行单元测试
python -m pytest tests/ -v
# 预期：7 passed
```

`validate.py` 检查：必备文件齐全、无悬空引用、必备标题、行预算、SKILL.md 硬不变量锚点、以及废弃概念残留的软警告。

## 五、MCP（可选）

检索核验层可插拔：运行时探测当前环境接上的专业法律库 MCP（北大法宝 / 法信 / 元典等），接上则实时核验并标 `[MCP核验:源名/条号或案号/日期]`；未接则回退模型知识并标 `[模型知识-未验证]`，高风险命题强制叠加二次核验提示。不写死任何具体 MCP 名称，以实际探测结果填入。纯分析路径**零外部依赖**。

---

## 六、免责声明

每份正式交付均附以下免责声明（定稿见 `references/49-citation-disclaimer.md`），不得省略：

> **本报告为基于所提供材料及公开检索结果的专业分析，不构成最终法律意见**，不替代主办律师对具体个案的判断与签字责任。所引法条及司法解释以检索时现行版本为准；凡未经外部源核验的命题均已在"来源与核验"节标注，据此行动前请经执业律师复核确认。标注 `[模型知识-未验证]` 的命题不得作为诉讼或法律交付物的唯一依据。

---

## 七、边界（与 contract-review 的分工）

| 本 skill（legal-research） | contract-review |
|---|---|
| 法律研究报告（论证法律问题） | 合同审查 + 风险清单 |
| 类案检索报告（裁判规则归纳） | 可选 Word 红线稿 |

**本 skill 不做**：合同审查（请使用 `contract-review`）、合同起草、企业核验、尽调合规、续约提醒、流程图。

---

## 八、获取

**方式 A（推荐，使用者）—— 从 Releases 下载压缩包**
到本仓库 Releases 下载 `legal-research-<版本>.zip`，解压得到完整的 `legal-research/` 文件夹。

**方式 B（维护者）—— 克隆源码**
```bash
git clone https://github.com/Tsinglaw/Legal-Agent-Skills.git
```
skill 位于 `legal-research/`。

解压或克隆后，把 `legal-research/` 文件夹交给 agent（放进 skill 目录，或让 agent 读取并遵循 `legal-research/SKILL.md`）。skill 会自定位：所有内部路径相对 `SKILL.md` 所在目录解析，与当前工作目录无关。
