# 分析薄护栏

本文件只装模型默认会错/会空/不肯结构化的 delta。推理方法（目的解释、But-for、涵摄）模型自发会做，一律不复述。骨架按「触发条件」按需加载本文件某一项；终检门 QC4 据触发条件反查是否漏用。凡未触发的项不必套用。

---

## 类推适用

**触发条件**：无直接可涵摄规范，拟援引邻近条文类推填补。亦用于评估类案与本案的相似度（检索/归纳骨架的类案筛选）。

- **三层相似度**（缺一层即类推不成立，须逐层过）：表面相似（事实要素）→ 结构相似（法律关系构造）→ **目的相似（规范意旨一致，决定性层）**。
- **红线 · 类推禁区**：刑法（罪刑法定）、税法（税收法定）**禁止不利类推**（不得类推入罪/加重、类推增设纳税义务）；行政处罚同理。触及即停，改走文义/体系解释或认定法无明文。
- **正当性三重论证**（缺一即降为「参考」）：① 规范目的可及于待决事实；② 同等对待（不类推则违反平等）；③ 体系一致（不与其他条文冲突）。

## 因果认定

**触发条件**：因果关系要件涉争。

- 默认用 **But-for**（无此行为则无此结果）。
- **切换 NESS 的三种场景**（But-for 在此失灵，必须切）：过度决定（两个各自充分的原因并存）/ 双重因果（数因同时致同一结果）/ 累积因果（单独不足、合并才足）。→ 改问「该行为是否为某个足以致果的最小充分条件集合中不可缺的一员」。
- **最小偏离**：构造反事实时只移除涉案行为，其余事实一律保持原样，不顺手改动无关变量。
- **5 类偏差速记**（对照排查）：后见之明偏差 / 反事实滑坡（多米诺无限外推）/ 混淆条件与原因 / 忽略介入因素 / 倒果为因。

## 目的解释

**触发条件**：法条文义有合理争议，需借规范目的定向。

- 四维要点（精简）：立法者主观目的（立法资料/说明）· 法律客观目的（现行体系下的合理功能）· 历史沿革 · 现实后果。主客观冲突时说明取舍理由，不静默择一。
- **红线 · 禁口号**：目的必须写成「**通过〔手段〕实现/防止〔具体效果〕**」的可检验命题。禁止「保护当事人合法权益」「维护交易秩序」「促进社会公平」式空话——这类表述不构成解释，视为未论证。

## 体系解释

**触发条件**：需确定某条在规范体系中的位置或与他条的关系。

- **由近及远检查清单**（依序过，不得跳级）：本条内部（款/项/但书）→ 本节/本章 → 本编/本法关联条文 → 上位法 → 特别法/新法（优于一般法/旧法）→ 司法解释。
- 每跳一级记录是否改变前一级结论；出现「特别法/新法优先」适用冲突规则并注明。

## 涵摄

**触发条件**：进入涵摄环节，需将规范涵摄到本案事实时。

四段模板，逐段落地，不跳步：

| 段 | 内容 |
|----|------|
| 大前提 | 规范要件拆解为可判断的构成要素（逐个列出） |
| 小前提 | 本案事实对每个要素的对应（一事实对一要素） |
| 涵摄 | 逐要素判断「事实是否落入要素」，含否定要素 |
| 结论 | 全部要素成立→法律效果；任一不成立→说明缺哪个 |

- **木桶置信度**：整体置信度 = 最弱节点置信度，**不得对各节点加权平均**。最弱节点（事实存疑/要素模糊/法条效力存疑）即整体上限，须点名。

## 论证强度自评

**触发条件**：形成结论与建议、给主张成立可能性定级时。

- 六维评分（各 1–5）：法律依据充分性 · 事实基础扎实度 · 逻辑链完整性 · 反驳意见考量 · 权威支撑位阶 · 结论确定性。
- **红线 · 致命缺陷否决**：**法律依据**或**事实基础**任一触底（=1）→ 整体强度直接降至「弱/条件性」，**不得被其余高分加权平均掩盖**。报告须显示该否决，不静默平滑。

## 证据分析

**触发条件**：涉举证责任或证据评价。

- **证据-要件挂钩矩阵**（行=证据，列=待证要件；★=直接证明，○=间接/需补强，空=不涉）：

  | 证据＼要件 | 要件A | 要件B | 要件C |
  |-----------|-------|-------|-------|
  | 证据1 | ★ | ○ |  |
  | 证据2 |  | ★ | ○ |

- **证据缺口模板**（每个空缺列一行）：〔缺口位置=哪个要件无★〕+〔风险等级 高/中/低〕+〔补救=需何种证据/能否补强/举证责任在谁〕。
- **五类证明力高低对照**（无相反情形时的一般位序，个案可推翻并说明）：

  | 证据类型 | 一般证明力 | 主要削弱点 |
  |---------|-----------|-----------|
  | 书证（原件） | 高 | 真伪/篡改 |
  | 鉴定意见 | 高 | 资质/程序/检材 |
  | 电子数据 | 中 | 完整性/来源可信 |
  | 证人证言 | 中低 | 利害关系/记忆 |
  | 当事人陈述 | 低 | 自利倾向，需佐证 |

## 领域陷阱清单（可扩充）

**触发条件**：命中对应法律关系时逐条对照；遇新陷阱在此追加并回记建档。

- **经营范围重合 ≠ 竞争关系**：须看实际主营、产品/服务重叠、市场对象，不凭营业执照。
- **签了竞业协议 ≠ 当然有效**：另查主体适格（高管/技术/保密人员）+ 商业秘密存在 + 劳动者实际接触 + 补偿约定。
- **合同未过工商登记 ≠ 合同无效**：股权转让等，登记多为对抗要件，不影响合同本身效力。
- **劳动争议仲裁前置**：多数劳动争议须先经劳动仲裁，不得直接起诉。
- **近期修法条号变动**：2025《反不正当竞争法》修订后条序变动，引用前必核现行条号（配合层A效力检查）。
