# 劳动/劳务 审查卡（中国法）

## 适用识别（关键词/语义场景）
劳动合同、劳务合同、聘用、入职、试用期、竞业限制、经济补偿、劳务派遣、非全日制、实习/见习。**先判用工性质**（劳动关系 / 劳务 / 承揽 / 劳务派遣 / 实习），性质不同则适用法律不同。

## 法律原则要点
> 只写原则，精确阈值（试用期分档月数、补偿计算封顶、竞业补偿比例等）与现行条文经 MCP 核验。
- **关系定性优先**：劳动关系适用劳动法/劳动合同法的强制规范；劳务、承揽、劳务派遣、实习一般不适用劳动合同法（如劳务用工无法定经济补偿、社保强制等），审查前须先定性。
- 试用期：上限随合同期限分档递增，**最长不超过六个月**；合同期限过短（如不满三个月）或以完成一定工作任务为期限的不得约定试用期；同一用人单位对同一劳动者**只能约定一次**试用期（精确分档以现行法及 MCP 核验为准）。试用期工资有法定下限（不低于本单位同岗最低档或约定工资的一定比例，且不低于当地最低工资）。违法约定且已履行的超期试用期，用人单位应按试用期满月工资标准、就超过法定试用期的已履行期间支付赔偿金。
- 竞业限制：**仅可对高级管理人员、高级技术人员和其他负有保密义务的人员**约定，对普通员工约定效力存疑；期限有上限（一般不超过两年）；**必须在竞业限制期限内按月支付经济补偿**，未约定补偿或未按月支付将影响条款约束力与可执行性。
- 经济补偿：按劳动者工作年限计（每满一年一个月，不满一年的按规则折算，月工资有封顶）；用人单位依法定情形解除但未提前通知的，另付一个月工资作**代通知金（即 N+1 的唯一触发，与"劳动者是否同意续订"无关）**；用人单位维持或提高约定条件续订、劳动者不同意续订的，属**无需支付经济补偿**的法定例外；违法解除按经济补偿标准的**二倍**支付赔偿金。
- 服务期与培训违约金：约定服务期的，违约金不得超过用人单位提供的培训费用，且应按未履行服务期占约定服务期的比例扣减。
- 强制性底线：工时、加班、最低工资、社会保险与住房公积金为强制事项，以约定排除或规避的相应条款无效。

## 审查卡
- 关系性质：是劳动关系还是劳务/派遣/实习，据以确定适用法与强制规范。
- 试用期：期限与合同期限是否匹配、是否只约定一次、试用期工资是否达法定下限。
- 竞业限制（如约定）：人员范围是否适格、期限/地域是否合理、经济补偿是否按月支付、违约金是否合理。
- 解除与经济补偿：解除情形是否合法、经济补偿/代通知金/2N 计算是否正确、通知程序是否履行。
- 服务期/培训：违约金是否超培训费用、是否按未履行比例扣减。
- 工时/工资/社保：是否符合强制标准、有无以约定变相规避。

## 领域专属失败模式
- 未先判用工性质，把劳务/派遣/实习当劳动关系审（或反之），整套强制规范错位适用。
- 竞业限制对普通员工约定、或漏掉按月经济补偿，导致条款约束力与可执行性存疑。
- 把"劳动者不同意续订"误当 N+1；或把"用人单位维持/提高条件续订被拒"这一**无需补偿**情形错当成需支付补偿。
- 服务期违约金超过培训费用、或未按未履行比例扣减。
- 试用期超法定上限或重复约定，漏掉超期部分的赔偿金责任。

## 该类典型 deal-breaker
- 以约定排除社保、最低工资、工时等强制性规范。
- 对不适格人员（普通员工）约定竞业限制且无经济补偿，却主张高额违约金。
- 名为劳务/承揽实为劳动关系，借此规避社保与经济补偿等强制义务。
