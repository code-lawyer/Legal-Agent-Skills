# 研究报告结构

本文件定义**研究模式**（及复合模式）的最终输出格式。输入来自 `03-research-mode.md` 八步论证骨架的完成产物；引证规范与免责声明见 `07-citation-currency.md`（本文件不重抄）。

复合模式（含类案深度支撑）同样使用本结构，"司法实践"节内嵌 `04-case-mode.md` 输出。

---

## 报告节次总览（顺序固定）

```
1. 执行摘要
2. 问题与范围
3. 法律框架
4. 学说
5. 司法实践
6. 分析（要件 / 举证 / 证据）
7. 结论与建议
8. 来源与核验
```

每节对应 `03-research-mode.md` 的一个或多个步骤；各节说明如下。

---

## 第一节：执行摘要

**对应**：步骤七（结论）的压缩版，置于报告最前。

内容要求：

- 3–5 行，先给结论，再给核心依据和最主要风险。
- 遵守执业级写作姿态：有实际结论，不用"需要具体分析"作占位。
- 若存在多条争议点，每条一行结论，后续正文分节展开。

```
示例格式：
本报告就争议点[X]得出结论：[主张成立可能性：高/中/低]。
核心依据：[1–2 条法律依据简述]。主要风险：[1 条最高风险]。
```

---

## 第二节：问题与范围

**对应**：步骤一（问题界定）+ `01-intake-scoping.md` 建档产出。

内容要求：

1. **争议点**：疑问句式，逐条列出（与建档产出一致，不改写）。
2. **法律关系**：当事人角色 + 关系类型（劳动/合同/侵权/知产……）。
3. **分析范围**：
   - 材料清单（已读文件 + 读取范围；失败项明说）。
   - 法域（默认：中国法；如涉其他法域，注明并说明分析策略）。
   - 时间基准（以检索日期为准的现行有效法律；如有时效约束，注明截止点）。
4. **本报告不覆盖的事项**（如有明确排除内容，列出）。

---

## 第三节：法律框架

**对应**：步骤三（法律框架）。

内容要求：

1. 按请求权路径（或法律关系主线）组织，逐条列出适用法条与司法解释。
2. 每条引证遵守 `07-citation-currency.md` § 一的四字段格式（法名 + 条号 + 施行日期 + 效力状态 + 来源标签）。
3. 已废止法条仅可在"历史沿革"子节出现，须加标注"仅作历史沿革引用，不适用于现行分析"。
4. 若同一事项存在上位法与下位法冲突，在此指出，不静默选择其一。

---

## 第四节：学说

**对应**：步骤四（学说与观点）。

内容要求：

1. **有争议时**：呈现主流说 + 少数说 + 各自核心理由 + 司法倾向（与第五节呼应）。
2. **无争议时**：一句话说明"法条含义明确，学说无实质分歧"，节名保留但内容可简短。
3. 学说来源标扩展源标签；效力低于优先源，须注明。
4. 不得以学说代替法条作为结论的唯一支撑。

---

## 第五节：司法实践

**对应**：步骤五（司法实践）。

内容要求：

1. 按效力位阶分层呈现（指导性案例 → 公报案例 → 最高院其他案例 → 高院案例 → 中基层案例）。
2. 每案引证遵守 `07-citation-currency.md` § 二的四字段格式（案号 + 法院 + 审级 + 裁判日期 + 来源标签）。
3. 归纳裁判规则：跨案提炼共识性裁判规则（可用列表）；如存在分歧，说明分歧成因（法院层级/地域/时间段）。
4. **复合模式**：在此节内嵌 `04-case-mode.md` 的检索路径 + 类案清单 + 裁判倾向统计子节。
5. **检索为空**：明确披露"未检索到类案"，不编造案号；说明对结论可靠性的影响。

---

## 第六节：分析（要件 / 举证 / 证据）

**对应**：步骤六（要件事实 + 举证责任 + 证据清单）。

内容要求：

1. **要件事实对照**：逐条列出请求权构成要件，对照用户事实材料标注"已有证明 / 缺口 / 待补充"。
2. **举证责任分配**：明确主张方 / 抗辩方的举证范围；适用举证责任倒置规则时说明法律依据。
3. **证据清单**：按要件分组，格式同 `03-research-mode.md` 步骤六 § 6.3 的表格（要件 | 建议证据 | 来源/取证方式 | 备注）。
4. **对方反驳预判**：列出对方最可能援引的反驳点，并说明应对方案。

---

## 第七节：结论与建议

**对应**：步骤七（结论与建议）。

本节遵守执业级写作姿态：直接给结论，不采用学生化占位。

内容要求：

1. **实际结论**：
   - 每条争议点一个结论（主张成立可能性：高/中/低 + 核心理由）。
   - 如为条件式结论，明写前提条件，不以"需要具体分析"代替。
2. **裁判风险**：1–3 条最主要风险，每条含风险等级（高/中/低）+ 理由 + 来源（对应第五节哪类案例）。
3. **可替代请求**：主请求有被驳回风险时，提出备位/替代请求方案及其法律基础。
4. **下一步行动**：可操作清单——补充证据、核实法条现行状态、协商策略、时效提示。

---

## 第八节：来源与核验

**对应**：`07-citation-currency.md` § 五（报告"来源与核验"节模板）+ 免责声明。

本节按 `07-citation-currency.md` 定义的模板成稿，**不在本文件重抄**。须包含：

1. **MCP 接入状态**：已接✓ / 未接—引用源于模型知识需核实。
2. **本地库检索范围**：`corpus/statutes/` · `corpus/cases/`（`_index.md` 字段检索）。
3. **检索时间戳**：YYYY-MM-DD。
4. **强制核验事项**（如有）：列出所有未能通过外部源核验的高风险命题，格式：
   ```
   ⚠️ 强制核验—尚未经外部源核实：
   - [命题]：引用源于模型知识，请主办律师手动核查。
   ```
5. **来源采信层级说明**（如有来源冲突）：说明冲突及采信决定。
6. **免责声明**：附 `07-citation-currency.md` § 六定义的完整免责声明定稿文本，不删减。

---

## 输出格式与交付规范

- 报告节次顺序固定，不可调换或省略节名（即使某节内容简短，保留节名并简短说明原因）。
- 行文风格：执业律师级——结论先行，法律依据精确，不堆列法条原文，不写模糊的"需要分析"。
- 对于多争议点报告：第三至第七节可在每节内按争议点分子节；第一节（执行摘要）保持全局一览视角。
- 本报告为内部研究文件；正式对外提交时需主办律师复核，并附 `07-citation-currency.md` § 六的免责声明。
