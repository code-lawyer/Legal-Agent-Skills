# 引证格式 · 来源标签 · 免责声明

本文件为所有分析模式（研究/检索/复合）共用的引证规范层，供 `40-output-research.md`、`41-output-case.md`、`20-research-skeleton.md`、`21-case-skeleton.md`、`48-qc-gate.md` 引用。**本文件只定义"怎么写引证"和"出什么免责"，时效强制核验逻辑不在此重写——见 `10-retrieval-core.md`（§ 规范效力检查 / 强制复核触发条件）。**

---

## 一、法条引证格式

每处法条引用**必须包含以下四字段**，缺一不可：

| 字段 | 说明 | 示例 |
|------|------|------|
| **法名** | 官方全称（含"中华人民共和国"前缀，简称括号内注） | 《中华人民共和国劳动合同法》（以下简称《劳动合同法》） |
| **条号** | 精确条款序号，含款/项时写明 | 第87条第1款 |
| **施行日期** | 现行版本施行之日（非公布日） | 施行日期：2008年1月1日 |
| **效力状态** | 现行有效 / 已修正（注明修正日期）/ 部分有效 / 已废止 / 已到期 / 未生效 / 存疑（见 10-retrieval-core.md 七级状态） | 效力状态：现行有效 |

**行内引证示例（报告正文）：**

```
《劳动合同法》第87条（施行：2008-01-01，现行有效）规定……[MCP核验:北大法宝/第87条/2008-01-01]
```

**注意事项：**
- 条文序号因修订发生变动（如 2025 年《反不正当竞争法》修订）时，必须核查现行条号，不得沿用旧序号；适用 `10-retrieval-core.md` 的强制复核触发条件。
- 施行日期填版本施行日，修正后版本须写最近修正施行日。
- 效力状态"已废止"的法条仅可作历史沿革引用，不得作为现行依据。

---

## 二、案例引证格式

每处案例引用**必须包含以下四字段**：

| 字段 | 说明 | 示例 |
|------|------|------|
| **案号** | 完整案号，含年份、法院代字、案件类型缩写、序号 | （2023）京01民终12345号 |
| **法院** | 作出裁判的法院全称 | 北京市第一中级人民法院 |
| **审级** | 一审 / 二审 / 再审 / 申请再审 / 执行 | 二审 |
| **裁判日期** | 裁判文书落款日期（YYYY-MM-DD） | 2023-06-15 |

**行内引证示例（报告正文）：**

```
参见（2023）京01民终12345号，北京市第一中级人民法院，二审，裁判日期2023-06-15 [MCP核验:北大法宝/（2023）京01民终12345号/2023-06-15]
```

**注意事项：**
- 案号格式不得省略括号与年份。案号存疑时（如仅有非正式摘录），标 `[模型知识-未验证]` 并注明"案号待核实"。
- 区分权威位阶：指导性案例 > 公报案例 > 最高院其他案例 > 高院案例 > 中基层案例；位阶须在案例引证后注明（如"最高人民法院指导案例第XX号"）。
- 类案引证在检索报告中可批量列表，但每案仍须保留四字段完整性。

## 三、来源标签（与 10-retrieval-core.md 完全一致）

每个法律命题（无论法条还是案例）**必须挂且仅挂一个来源标签**，标注其验证渠道。来源标签**只有两值**，字符串需与 `10-retrieval-core.md` 逐字一致：

### 1. MCP 核验命中

```
[MCP核验:源名/案号或条号/日期]
```

示例：`[MCP核验:北大法宝/（2023）京01民终12345号/2023-06-15]`

核验状态：**已核验**（以实际探测接上的 MCP 名称填入"源名"，不得写死或虚填）。

### 2. 模型知识回退

```
[模型知识-未验证]
```

核验状态：**未验证**。MCP 未接或查空时回退于此。高风险命题（精确条号/具体阈值/利率倍数/司法解释最新状态）在此标签后**强制叠加二次检索提示**，不得以单一模型知识作为结论支撑。

### 标签使用规则

- 两类标签互斥，每命题选一，且必须选一（不得留空）。
- 标签描述**实际来源行为**，不描述自信程度，不得虚标。
- 来源标签为「验证渠道轴」，与「权威位阶轴」（效力状态 / 案例位阶 / 其他权威五级）正交，两轴可叠加，互不替代——具体位阶取词见 `10-retrieval-core.md`。

---

## 四、状态标签轴（与来源标签叠加，互不替代）

状态标签描述命题在核验过程中的**处置状态**，与「来源标签」（怎么来的）、「权威位阶」（多权威）分属三条不同的轴，三者可同时出现在同一命题后：

- `[前提已标记-请核实]`：用户在原始输入中引用的法条/案例/日期/阈值经核实与已知信息冲突，需当面向用户提出。
- `[需审查]` 等其他执业提示性标签：视具体骨架/护栏文件定义按需使用。

**示例（三轴叠加）：**

```
《反不正当竞争法》第9条（现行有效）[MCP核验:国家法律法规数据库/第9条/2025-10-15][前提已标记-请核实]
```

## 五、时效强制核验（指引，不重复正文）

本节不重列核验触发清单，以保持 DRY。

**执行时请参阅：** `10-retrieval-core.md` § **规范效力检查（决策树式）** 与 **强制复核触发条件**

该节以「当且仅当」式布尔条件定义七级效力状态与具体可检测的强制复核触发情形（如"发布超 10 年未见修正记录""司法解释早于其所释法律的最新修正"）。

**报告层的衔接动作（在本层执行）：**
- 凡命题触发强制复核情形，若已经 MCP 核实，标来源标签即可。
- 若尚未核实（MCP 未接/查空），须在报告"来源与核验"节统一列出，格式：

```
⚠️ 强制核验—尚未经外部源核实：
- [命题1]：引用源于模型知识，请主办律师手动核查。
- [命题2]：同上。
```

不在正文每处刷横幅；集中于"来源与核验"节一次性披露。

---

## 六、报告"来源与核验"节模板

研究报告与检索报告的末尾均须附"来源与核验"节，格式如下（按实际情况填写，无内容则省略对应行）：

```
## 来源与核验

- MCP 接入状态：[已接✓ / 未接—引用源于模型知识需核实]
- 检索时间戳：YYYY-MM-DD
- 强制核验事项（如有）：
  ⚠️ 以下命题未能通过外部源核验，引用源于模型知识，需主办律师核实：
  - [命题列表]
- 来源采信层级说明（如有来源冲突）：[说明冲突及采信决定]
```

## 七、免责声明定稿文本

以下为正式交付附页免责声明，**可直接粘贴**，不得删减：

---

**【免责声明】**

**成稿原则：** "不构成最终法律意见、需主办律师复核"

本报告为基于所提供材料及公开检索结果的专业分析，**不构成最终法律意见**，不替代主办律师对具体个案的判断与签字责任。

本报告所引法条及司法解释以检索时现行版本为准；法律时效性问题（精确条号、数字阈值、利率倍数、司法解释最新状态等）凡未经外部源核验者均已在报告"来源与核验"节标注，**据此行动前请经执业律师复核确认**。

本报告中标注 `[模型知识-未验证]` 的命题尚未经外部来源核实，不得作为诉讼或法律交付物的唯一依据。

---

上述免责声明为研究报告与检索报告的固定页脚，任何正式交付（含简单问答外的书面输出）均须附上，不得省略。
