# 检索报告输出结构

本文件定义**检索模式**生成的类案检索报告的六节标准结构，
供 `04-case-mode.md` 六步骨架执行完毕后按序填充输出。

引证格式（案号四字段、来源标签）及免责声明见 `07-citation-currency.md`，
**本文件只定义"出哪些节 / 各节放什么"，不重复引证规则正文（DRY）**。

---

## 报告节次总览

```
§1 检索概述（含检索式回显）
§2 类案清单（分层 + 排除理由）
§3 裁判规则归纳
§4 裁判倾向统计
§5 个案启示
§6 来源与核验
附：免责声明
```

---

## §1 检索概述

**内容要求**：

1. **任务描述**：一句话说明本次检索的事实模式（来自 `04-case-mode.md` 步骤一输出）：
   案由 + 争议焦点 + 当事人类型 + 检索范围（时间/地域/审级）。

2. **检索式回显（必须）**：将 `04-case-mode.md` 步骤二记录的三轮检索式原样呈现，
   使读者无需重跑检索即可验证检索路径：

   ```
   轮1检索式：[原文]  → 命中 N 件
   轮2检索式：[原文]  → 命中 N 件（新增 M 件）
   轮3检索式：[原文]  → 最终候选池 N 件
   ```

3. **候选池摘要**：候选池总量、纳入（高度类似+部分类似）数量、排除数量。

4. **检索时间戳**：YYYY-MM-DD（供时效判断）。

> 检索式回显是本节的核心——没有回显则报告无法复现，不可省略。

---

## §2 类案清单

**内容要求**：

按相似度分层（来自 `04-case-mode.md` 步骤三输出），每件案例引证格式遵循
`07-citation-currency.md` § 二（案号 + 法院 + 审级 + 裁判日期）并挂来源标签。

### 2.1 高度类似案例（N 件）

表格或列表，字段：案号、法院、审级、裁判日期、裁判结果摘要（一句话）、相似要素说明。

### 2.2 部分类似案例（N 件）

同上，额外加"差异点"列，注明与用户事实的主要差异（1–2条）。

### 2.3 参考案例（N 件）

仅列案号、法院、说明参考价值；注明"仅作参考，不计入倾向统计"。

### 2.4 排除案例说明

列出排除案例数及主要排除原因（不需逐案展开，原因分类归并即可）：

```
排除 N 件，原因分布：核心事实不符（X件）/ 案号疑似存疑（Y件）/ 已超时间范围（Z件）
```

---

## §3 裁判规则归纳

**内容要求**（来自 `04-case-mode.md` 步骤四输出）：

### 3.1 说理共识规则

逐条列出跨案共识规则命题，每条注明支撑案例数与最高效力位阶来源：

```
规则一：[命题表述]
  支撑案例：（案号1）[来源标签]、（案号2）[来源标签]（共 N 件）
  最高位阶来源：[指导性案例/公报案例/最高院案例/高院案例]
```

### 3.2 说理分歧点

并列呈现不同裁判路径，不强行合并为单一结论：

```
分歧点一：[争议描述]
  路径甲：[理由摘要]——代表案例：（案号）[来源标签]
  路径乙：[理由摘要]——代表案例：（案号）[来源标签]
  实践建议：优先援引 [高效力位阶路径]，低位阶路径作备位论点。
```

### 3.3 检索空或规则不足时的处理

若高度类似案例为零，在本节写明：
"未检索到足量类案，无法归纳裁判规则；以下为基于法律框架的推演，标 `[模型知识-未验证]`。"

---

## §4 裁判倾向统计

**内容要求**（来自 `04-case-mode.md` 步骤五输出）：

### 4.1 基础统计表

仅基于**高度类似**案例（样本 N）：

| 裁判走向 | 件数 | 占比 |
|----------|------|------|
| 支持主张 | n₁ | n₁/N |
| 不支持主张 | n₂ | n₂/N |
| 部分支持/条件成立 | n₃ | n₃/N |

**样本不足强制披露（N ≤ 5 时必须出现）：**

```
⚠️ 样本警示：高度类似案例仅 N 件（N 偏小），以下比例仅供参考，不代表裁判规律，
请主办律师结合实际情况判断，不得单独援引本统计作为结论依据。
```

### 4.2 关键变量分析（N 足够时展开）

- **法院层级**：最高院/高院/中院/基层院支持率对比（如有差异则说明）。
- **地域**：省市间裁判倾向有无系统分化（如有则给出方向）。
- **时间趋势**：近三/五年走向是否有变化（关联立法修订或新指导性案例）。

若 N 过小无法展开分析，各小节填写"样本量不足，不展开变量分析"，不强行给结论。

### 4.3 统计局限性说明

说明本统计的方法局限：
- 检索工具覆盖度（仅检索到 MCP/本地库可查文书，存在检索盲区）；
- 公开裁判文书的代表性局限（和解/调解案件不在统计内）；
- 时效局限（统计时间截至 [检索时间戳]，此后新发案例不在其中）。

## §5 个案启示

**内容要求**（来自 `04-case-mode.md` 步骤六输出）：

1. **裁判走向预判**：基于用户事实与类案的高权重要素对比，给出预判（高/中/低可能性）
   及 1–3 条核心理由；若样本不足，给条件式预判（"若 X 成立，则走向 Y"）。

2. **关键变量对照**：用户事实所属法院层级、地域是否落在统计的有利区间。

3. **可操作建议**：
   - 证据补强方向（对照 §3 规则归纳的胜诉关键要件）；
   - 论点选择（优先援引高位阶裁判路径）；
   - 时效与时机（近期修法/新指导性案例提示，建议强制核验，
     触发 `02-retrieval.md` § 强制核验触发（时效））。

4. **局限性说明**：若启示受样本不足或 `[模型知识-未验证]` 来源制约，明确标注。

## §6 来源与核验

按 `07-citation-currency.md` § 五模板成稿（模板字段定义以 07 为准，本文件不重抄）。
检索报告仅涉案例库，故模板中「本地库检索范围」填 `corpus/cases/`。
时效强制核验逻辑见 `02-retrieval.md` § 强制核验触发（时效），本节不重复。
