# 借款/融资 审查卡（中国法）

## 适用识别（关键词/语义场景）
借款、贷款、借贷、融资、民间借贷、借条/欠条、流动资金借款、股东借款、过桥资金；以资金融通为核心的交易。涉股权融资/增资对赌的，同时参照公司类条款。

## 法律原则要点
> 只写原则，精确阈值（利率倍数上限、担保登记具体规则等）与现行条文经 MCP 核验。
- 本金认定：预先在本金中扣除利息（"砍头息"）的，本金按借款人**实际收到（到账）**的金额认定，不按票面数额。
- 利率上限：约定利率超过法律规定的司法保护上限（以合同成立时法定基准的一定倍数为准，精确倍数经 MCP 核验）的部分不受保护；**须先区分主体**——持牌金融机构借款与自然人/企业间民间借贷适用规则不同。
- 变相高息：服务费、咨询费、管理费、复利、保证金等变相突破利率上限的安排，穿透后与利息合并计算，超出部分不受保护。
- 担保从属性：担保随主债务，主债务无效/消灭则担保原则上随之；保证方式（一般保证/连带责任保证）约定不明的推定、抵押（不动产登记生效、动产登记对抗）与质押（登记或交付）的设立/对抗规则，具体经 MCP 核验。
- 提前还款与加速到期：提前还款时利息按实际借款期间计算；加速到期条款的触发条件与通知程序应明确、可执行。
- 融资场景（如涉对赌/回购）：与目标公司对赌 vs 与股东对赌的效力差异；涉公司回购的，须履行减资等法定程序、不得损害公司债权人利益（原则，经 MCP 核验）。

## 审查卡
- 本金与交付：借款金额、实际到账金额、是否存在砍头息、交付凭证是否留存。
- 利率与计息：利率水平、计息方式、是否复利；逾期利率/罚息/违约金**合计**是否超司法保护上限。
- 期限与还款：借款期限、还款计划、提前还款利息处理、加速到期触发与通知。
- 担保：保证（一般/连带）、抵押、质押是否有效设立、是否办理登记、能否执行。
- 主体性质：民间借贷 vs 持牌金融机构，据以适用不同规则。
- 融资专项（如涉）：对赌对象、回购程序与前提、清算优先权、反稀释机制。
- 争议解决与管辖：是否明确、是否有效。

## 领域专属失败模式
- 只看票面本金，漏掉砍头息导致本金认定与利息计算基数错误。
- 只算约定利率，漏掉服务费/罚息/违约金叠加后的**实际综合资金成本**已超上限。
- 把民间借贷规则套用到持牌金融机构借款（或反之），适用规则错位。
- 对赌条款不区分"与公司"还是"与股东"，漏掉公司回购的减资程序前提与债权人保护。
- 担保条款漏掉设立/登记要件，担保落空而主债权无实质保障。

## 该类典型 deal-breaker
- 综合资金成本明显超过法定司法保护上限，且无调整/补正空间。
- 名为借款实为非法吸收公众存款、变相集资等触及刑事/金融监管红线的结构。
- 担保或还款安排以规避金融监管、外汇管理等强制性规定为目的。
