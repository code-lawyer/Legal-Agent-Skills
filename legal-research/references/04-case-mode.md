# 检索模式：案例/事实导向检索归纳骨架

本文件定义**检索模式**（及复合模式内嵌子流程）的六步执行骨架，原创于本 skill——
参考项目中无任何现成"检索式→类案筛选→裁判规则归纳→裁判倾向统计"的完整流程，本文件为第一次写定。

进入本流程前，`01-intake-scoping.md` 已完成检索模式建档（事实模式锚点已抽取）；
检索核验层 `02-retrieval.md` 提供三轮检索动作与每轮检索式留痕规范；
引证格式与免责声明见 `07-citation-currency.md`。

---

## 前置确认

执行本骨架前，确认以下三项：

- 检索模式建档已完成（`01-intake-scoping.md` § 三，四个锚点维度已输出）。
- 当前法域已确定（默认：中国法）。
- 检索核验动作（含三轮检索式留痕）参见 `02-retrieval.md` § 三轮检索策略。

---

## 步骤一：事实模式提取

**目的**：把 `01-intake-scoping.md` 的建档锚点精炼为可直接驱动检索的四维结构，
同时识别最影响类案相似度判断的关键事实要素。

**操作**：

1. 从建档产出取出四维锚点（案由、关键事实要素、争议焦点、当事人类型）——若有缺口，
   在此再次确认；仍缺则标"待补充"，不捏造。
2. 对关键事实要素做**权重排序**：
   - 高权重：决定裁判定性的核心事实（如"是否签竞业协议""补偿金是否支付"）；
   - 低权重：不影响裁判结果的周边事实（合同签订地、具体金额数字等）。
   高权重事实将成为步骤三类案相似度判断的主要标准。
3. 明确**类案检索的预设范围**（时间、地域、审级），对应建档产出中的检索范围字段。

**输出格式**：

```
【事实模式提取】
案由：[精确案由]
高权重核心事实：[逐条，≤5条]
低权重周边事实：[简列，不影响检索式]
争议焦点：[核心争点]
当事人类型：[主体特征]
检索预设范围：时间 [X年至今] · 地域 [全国/省市] · 审级 [全部/指定]
```

## 步骤二：检索式构造（三轮，每轮留痕）

**目的**：依托 `02-retrieval.md` 的三轮检索策略，按案例级联执行检索，
**每轮检索式必须在此记录**，后续步骤六的报告将原样回显（可复现）。

**执行规则**：

- 三轮检索均走案例级联：本地 `corpus/cases/`（_index.md 字段检索）→ 案例库 MCP 探测 →
  回退模型知识；标签分别为 `[本地库:案号/法院/裁判日期]` / `[MCP核验:源名/案号/日期]` /
  `[模型知识-未验证]`（格式同 `07-citation-currency.md` § 三）。
- 检索为空时：明确披露"本地库及 MCP 均未检索到"，不编造案号；
  在步骤六报告注明"缺乏类案佐证，统计结论不适用"。

**留痕格式（三轮逐一记录）**：

```
轮1检索式：[精确锚点，如案由关键词 + 高权重核心事实]
  → 命中：N 件（本地库 X / MCP Y / 模型知识 Z）

轮2检索式：[近义/别名/上位概念扩展，或放宽条件]
  → 命中：N 件（在轮1基础上新增 M 件）

轮3检索式：[去噪/歧义消解，加限定词或限定裁判日期]
  → 命中：N 件（最终有效候选池）
```

三轮汇总后形成**候选案例池**，进入步骤三筛选。

---

## 步骤三：类案筛选（相似度分层，可复现）

**目的**：对候选案例池做系统性筛选，按相似度分层，记录每案纳入或排除的理由，
确保筛选结论可复现（他人按同一标准可得相同结果）。

**相似度分层标准**：

| 层级 | 判定标准 | 报告处理 |
|------|----------|----------|
| **高度类似** | 高权重核心事实全部吻合（≥80%），案由与争议焦点一致 | 全量纳入裁判规则归纳与倾向统计 |
| **部分类似** | 高权重核心事实部分吻合（50%–80%），或案由一致但争议焦点有差异 | 纳入但在报告中注明差异点 |
| **参考** | 仅法律关系或案由相关，核心事实差异显著 | 单独列出，标注差异，不计入倾向统计 |

**筛选操作**：

1. 逐案对照高权重核心事实，逐维度勾选吻合/不吻合，得出层级结论。
2. **记录排除理由**：被排除案例（核心事实完全不符或案号疑似错误）须写排除原因，不可静默丢弃。
3. 若候选案例池为空或高度类似案例为零，明确披露，进入步骤六时给条件式结论，
   不强行出统计数字。

**输出格式**：

```
高度类似（N件）：[案号列表 + 相似事实摘要]
部分类似（N件）：[案号列表 + 差异点注明]
参考（N件）：[案号列表 + 差异说明]
排除（N件）：[排除理由简述]
```

## 步骤四：裁判规则 / 要点归纳

**目的**：跨案提炼裁判规则——不是逐案复述，而是从"高度类似 + 部分类似"案例中
归纳法官说理的**共识规则**与**分歧点**，形成可引用的裁判规则命题。

**归纳操作**：

1. **说理共识**：≥2 件案例共同采纳的裁判逻辑，提炼为规则命题，标支撑案例数。

   示例格式：
   ```
   规则A：[命题表述]——支撑案例：（案号1）、（案号2）[来源标签]
   ```

2. **说理分歧**：不同法院（或同院不同时期）对同一法律要件采用不同认定标准时，
   并列呈现两种说理路径及各自代表案例，不强行统一为一种结论。

   示例格式：
   ```
   分歧点X：[争议表述]
     路径甲：[理由] ——代表案例：（案号）[来源标签]
     路径乙：[理由] ——代表案例：（案号）[来源标签]
   ```

3. **效力位阶提示**：归纳规则时标注最高效力来源（指导性案例/公报案例/最高院案例/高院案例），
   低位阶规则注明"效力位阶：中基层法院，仅作倾向参考"。

4. 来源标签遵循 `07-citation-currency.md` § 二、§ 三格式；每案引证四字段齐全。

---

## 步骤五：裁判倾向统计

**目的**：在步骤三纳入样本的基础上，统计支持/不支持（或其他裁判走向）的比例，
并识别影响走向的关键变量。**此步骤以诚信披露为前提——样本不足时不强行出比例。**

**统计操作**：

1. **基础统计**：仅对"高度类似"样本做倾向统计（部分类似可附注参考）：
   - 支持主张：N 件
   - 不支持主张：N 件
   - 部分支持 / 条件成立：N 件
   - 总样本 N

2. **关键变量分析**（N 足够时展开）：

   | 变量维度 | 分析思路 |
   |----------|----------|
   | **法院层级** | 最高院 / 高院 / 中院 / 基层院的支持率是否有系统差异 |
   | **地域** | 不同省市（经济发达地区 vs 其他）裁判倾向是否存在分化 |
   | **时间趋势** | 近三/五年裁判走向是否有系统性转变（如立法修订后） |

3. **样本不足披露（强制）**：

   - 高度类似样本 N ≤ 5：**必须**在统计段首写明：
     ```
     ⚠️ 样本警示：高度类似案例仅 N 件（N 偏小），以下比例仅供参考，不代表裁判规律，
     请主办律师结合实际情况判断。
     ```
   - 样本为 0 或仅有参考层级案例：跳过统计，在步骤六给条件式结论，
     注明"现有样本量不支持倾向性统计结论"。

4. **不强行出比例**：检索空或样本极少时，不以百分比替代实质分析；
   有条件式结论（"若事实特征X成立，则倾向Y"）优于虚假的"50%/50%"。

---

## 步骤六：个案启示

**目的**：将步骤四的裁判规则和步骤五的裁判倾向，具体落到用户事实，
给出可操作的预判与行动建议（执业级，不学生化占位）。

**启示层次**：

1. **裁判走向预判**：对照用户事实的高权重核心事实，与"高度类似"样本的胜诉/败诉
   关键事实比较，给出预判（可能性：高/中/低）及核心理由（1–3条）。
   若信息不足，给条件式预判，不拒绝下结论。

2. **关键变量对照**：用户事实所属法院层级、地域是否落在步骤五统计中的有利区间？
   若存在地域/层级不利因素，明确提示。

3. **可操作建议**（结合裁判规则归纳得出）：
   - 补强证据方向：步骤四规则归纳中，哪些要件事实是胜诉关键，用户目前是否有对应证据。
   - 论点优化：若存在步骤四中的说理分歧，优先援引效力位阶更高的路径。
   - 时效与时机：是否有近期修法或新发指导性案例改变裁判走向，建议主办律师强制核验
     （触发 `02-retrieval.md` § 强制核验触发（时效））。

4. **局限性说明**：若样本不足（步骤五已披露），在此再次注明"建议补充检索后复核启示"；
   若大量来源为 `[模型知识-未验证]`，明确提示"来源核验不足，启示仅供初步参考"。
