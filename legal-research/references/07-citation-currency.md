# 公共引证规范 · 时效核验 · 来源标签 · 免责声明

本文件为所有分析模式（研究/检索/复合）共用的引证规范层，供 `05-output-research.md` 和 `06-output-case.md` 引用。**本文件只定义"怎么写引证"和"出什么免责"，时效强制核验逻辑不在此重写——见 `02-retrieval.md`（§ 强制核验触发（时效））。**

---

## 一、法条引证格式

每处法条引用**必须包含以下四字段**，缺一不可：

| 字段 | 说明 | 示例 |
|------|------|------|
| **法名** | 官方全称（含"中华人民共和国"前缀，简称括号内注） | 《中华人民共和国劳动合同法》（以下简称《劳动合同法》） |
| **条号** | 精确条款序号，含款/项时写明 | 第87条第1款 |
| **施行日期** | 现行版本施行之日（非公布日） | 施行日期：2008年1月1日 |
| **效力状态** | 现行有效 / 已修正（注明修正日期）/ 已废止 | 效力状态：现行有效 |

**行内引证示例（报告正文）：**

```
《劳动合同法》第87条（施行：2008-01-01，现行有效）规定……[本地库:劳动合同法/第87条/2008-01-01]
```

**注意事项：**
- 条文序号因修订发生变动（如 2025 年《反不正当竞争法》修订）时，必须核查现行条号，不得沿用旧序号；适用 `02-retrieval.md` 的强制核验规则。
- 施行日期填版本施行日，修正后版本须写最近修正施行日。
- 效力状态"已废止"的法条仅可作历史沿革引用，不得作为现行依据。

---

## 二、案例引证格式

每处案例引用**必须包含以下四字段**：

| 字段 | 说明 | 示例 |
|------|------|------|
| **案号** | 完整案号，含年份、法院代字、案件类型缩写、序号 | （2023）京01民终12345号 |
| **法院** | 作出裁判的法院全称 | 北京市第一中级人民法院 |
| **审级** | 一审 / 二审 / 再审 / 申请再审 / 执行 | 二审 |
| **裁判日期** | 裁判文书落款日期（YYYY-MM-DD） | 2023-06-15 |

**行内引证示例（报告正文）：**

```
参见（2023）京01民终12345号，北京市第一中级人民法院，二审，裁判日期2023-06-15 [MCP核验:北大法宝/（2023）京01民终12345号/2023-06-15]
```

**注意事项：**
- 案号格式不得省略括号与年份。案号存疑时（如仅有非正式摘录），标 `[模型知识-未验证]` 并注明"案号待核实"。
- 区分效力位阶：指导性案例 > 公报案例 > 最高院其他案例 > 高院案例 > 中基层案例；位阶须在案例引证后注明（如"最高人民法院指导案例第XX号"）。
- 类案引证在检索报告中可批量列表，但每案仍须保留四字段完整性。

## 三、来源标签（与 02-retrieval 完全一致）

每个法律命题（无论法条还是案例）**必须挂且仅挂一个来源标签**，并附核验状态。三种标签写法如下，字符串需与 `02-retrieval.md` 逐字一致：

### 1. 本地库命中

```
[本地库:法名/条号/版本日期]
```

示例：`[本地库:劳动合同法/第87条/2008-01-01]`

核验状态：**已核验**（本地库为用户预先录入核验，准确性最高）。

### 2. MCP 核验命中

```
[MCP核验:源名/案号或条号/日期]
```

示例：`[MCP核验:北大法宝/（2023）京01民终12345号/2023-06-15]`

核验状态：**已核验**（以实际探测接上的 MCP 名称填入"源名"，不得写死或虚填）。

### 3. 模型知识回退

```
[模型知识-未验证]
```

核验状态：**未验证**。高风险命题（精确条号/具体阈值/利率倍数/司法解释最新状态）在此标签后**强制叠加二次检索提示**，不得以单一模型知识作为结论支撑。

### 标签使用规则

- 三类标签互斥，每命题选一。
- 标签描述**实际来源行为**，不描述自信程度，不得虚标。
- 状态标签（`[前提已标记-请核实]`、`[需审查]` 等）为另一轴，可与来源标签叠加，互不替代。

## 四、时效强制核验（指引，不重复正文）

本节不重列核验触发清单，以保持 DRY。

**执行时请参阅：** `02-retrieval.md` § **强制核验触发（时效）**

该节定义了七类必须强制核验的情形（精确条号/数字阈值/利率倍数/最新司法解释/指导性案例/生效废止日期/跨境承认执行），以及判断准则（"律所快讯会不会设'近期动态'一节？会就必须查"）和典型案例（2025 年《反不正当竞争法》修订条号变动）。

**报告层的衔接动作（在本层执行）：**
- 凡报告中存在强制核验情形，若已经 MCP 或本地库核实，标来源标签即可。
- 若尚未核实（MCP 未接/查空），须在报告"来源与核验"节统一列出，格式：

```
⚠️ 强制核验—尚未经外部源核实：
- [命题1]：引用源于模型知识，请主办律师手动核查。
- [命题2]：同上。
```

不在正文每处刷横幅；集中于"来源与核验"节一次性披露。

## 五、报告"来源与核验"节模板

研究报告与检索报告的末尾均须附"来源与核验"节，格式如下（按实际情况填写，无内容则省略对应行）：

```
## 来源与核验

- MCP 接入状态：[已接✓ / 未接—引用源于模型知识需核实]
- 本地库检索范围：corpus/statutes/ · corpus/cases/（_index.md 字段检索）
- 检索时间戳：YYYY-MM-DD
- 强制核验事项（如有）：
  ⚠️ 以下命题未能通过外部源核验，引用源于模型知识，需主办律师核实：
  - [命题列表]
- 来源采信层级说明（如有来源冲突）：[说明冲突及采信决定]
```

## 六、免责声明定稿文本

以下为正式交付附页免责声明，**可直接粘贴**，不得删减：

---

**【免责声明】**

**成稿原则：** "不构成最终法律意见、需主办律师复核"

本报告为基于所提供材料、本地法规语料库及公开检索结果的专业分析，**不构成最终法律意见**，不替代主办律师对具体个案的判断与签字责任。

本报告所引法条及司法解释以检索时现行版本为准；法律时效性问题（精确条号、数字阈值、利率倍数、司法解释最新状态等）凡未经外部源核验者均已在报告"来源与核验"节标注，**据此行动前请经执业律师复核确认**。

本报告中标注 `[模型知识-未验证]` 的命题尚未经外部来源核实，不得作为诉讼或法律交付物的唯一依据。

---

上述免责声明为研究报告与检索报告的固定页脚，任何正式交付（含简单问答外的书面输出）均须附上，不得省略。
