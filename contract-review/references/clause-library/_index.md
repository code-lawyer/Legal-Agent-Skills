# 标准条款库（中国法）· 索引

> 本目录是**可选资源**：生成问题卡「建议修订文本【完整全文】」时，可查本库匹配**已验证的中国法标准措辞**，以其"推荐措辞"作为改后条款全文的基础（结合个案数额/期限具体化后使用），不必每次现拟。
>
> - **仅在判定法域 = 中国法时适用**。本 skill 为中美双法域；美国法/跨境合同不适用本库（跨境涉中国法一侧的条款可参考）。
> - **按需读取（渐进式披露）**：先用下方"风险关键词 → 条款ID"索引定位条款ID 及其所在类别文件，再**只读该类别文件**，不一次读全目录。
> - **与 `rules/cn/` 的关系**：`rules/cn/` 领域卡回答"该不该有此条、缺了有什么后果"（原则）；本库回答"若写得有问题，可直接落地的改后条款全文长什么样"（成品措辞）。二者术语、立场、风险口径一致。
> - **[待查] 纪律**：各条"法律依据"栏一律为"……相关规定 `[待查]`"，陈述的是法律规则的**实质内容**（如"违约金过高可请求酌减""竞业补偿须按月支付""定金不超过主合同标的额 20%"），对应现行条文序号须经 MCP/检索核验后方可作为已核验依据引用；本库不写死条号。
> - **推荐措辞的性质**：均为**完整、可直接落地的条款全文**（非"应约定 X"式提示）；`______` 为需结合个案填入的数额/期限/名称，不得机械留空照抄。
> - **适用立场字段**："中立"表示文本对双方相对均衡；标注"甲方/乙方"表示该措辞方向更利于该方，审对方立场时识别其对立主张空间（见该条"实务提示"）。
> - **不构成法律意见**：本库为审查/起草辅助参考数据，非独立技能，亦非正式法律意见；嵌入正式合同前须结合个案调整并自行完成法律核验。
