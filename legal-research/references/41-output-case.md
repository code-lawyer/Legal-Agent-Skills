# 检索报告结构

本文件定义**检索模式**的最终输出格式。输入来自 `21-case-skeleton.md` 七步骨架（步骤一至
六的检索/归纳产出 + 步骤七移交终检）；引证格式、来源标签、免责声明见
`49-citation-disclaimer.md`（本文件不重抄，DRY）。

**复合模式**：检索子流程内嵌于 `20-research-skeleton.md` 的司法实践步骤，产出就地呈现在
承载它的研究报告「司法实践」节中，不另出独立检索报告，也不单独走本结构。本结构仅供**独立
检索模式**成稿使用。

---

## 报告节次总览（顺序固定，6 节）

```
1. 检索概述
2. 类案清单
3. 裁判规则归纳
4. 裁判倾向统计
5. 个案启示
6. 来源与核验
```

第 1–5 节分别对应 `21-case-skeleton.md` 步骤二至步骤六的产出（步骤一「事实模式提取」并入
第 1 节任务描述，不单独成节）；第 6 节为跨步骤汇总产出，格式定义于
`49-citation-disclaimer.md` § 六。

---

## 第一节：检索概述

**对应**：`21-case-skeleton.md` 步骤一（事实模式提取）+ 步骤二（三轮检索式）。

内容要求：

1. **任务描述**：一句话说明本次检索的事实模式——案由 + 争议焦点 + 当事人类型 + 检索预设
   范围（时间/地域/审级），取自步骤一输出，不改写。
2. **检索式回显（必须）**：将步骤二三轮检索式原样呈现，含每轮命中数与查全率/查准率 KPI
   自评，使读者无需重跑检索即可验证检索路径与决策过程：

   ```
   轮1检索式：[原文] → 命中 N 件（MCP核验 X / 模型知识 Y）→ KPI：[达标/不足] → [动作]
   轮2检索式：[原文] → 命中 N 件（新增 M 件）→ KPI：……
   轮3检索式：[原文] → 最终候选池 N 件 → KPI：……
   ```

3. **候选池摘要**：候选池总量、纳入（高度类似 + 部分类似 + 参考）数量、排除数量。
4. **检索时间戳**：YYYY-MM-DD（供第六节时效核验引用）。
5. **检索为空时**：明确写明"MCP 与模型知识均未检索到候选案例"，不编造案号；提示第三至
   五节将采用条件式处理。

> 检索式回显是本节核心——没有回显则报告无法复现，不可省略。

---

## 第二节：类案清单

**对应**：`21-case-skeleton.md` 步骤三（类案筛选）。

内容要求：

按相似度分层呈现步骤三产出，每案引证遵守 `49-citation-disclaimer.md` § 二的四字段格式
（案号 + 法院 + 审级 + 裁判日期）+ 来源标签。

### 2.1 高度类似案例（N 件）

列表或表格，字段：案号、法院、审级、裁判日期、裁判结果摘要（一句话）、三层相似度结论
（表面/结构/目的，见 `30-analysis-guardrails.md`）。

### 2.2 部分类似案例（N 件）

同上，额外加"差异点"列，注明与用户事实的主要差异（1–2 条）。

### 2.3 参考案例（N 件）

仅列案号、法院、参考价值说明；注明"仅作参考，不计入第四节倾向统计"。

### 2.4 排除案例说明

列出排除案例数及排除原因分类归并（不逐案展开），与步骤三的排除记录一致：

```
排除 N 件，原因分布：核心事实不符（X件）/ 目的层不符（Y件）/ 案号疑似存疑（Z件）
```

---

## 第三节：裁判规则归纳

**对应**：`21-case-skeleton.md` 步骤四（裁判规则归纳）。

内容要求：

### 3.1 说理共识规则

逐条列出跨案共识规则命题，每条注明支撑案例数与最高效力位阶（指导性案例 > 公报案例 >
最高院其他案例 > 高院案例 > 中基层案例）：

```
规则一：[命题表述]
  支撑案例：（案号1）[来源标签]、（案号2）[来源标签]（共 N 件）
  最高效力位阶：[指导性案例/公报案例/最高院其他/高院/中基层]
```

### 3.2 说理分歧点

并列呈现不同裁判路径，不强行合并为单一结论：

```
分歧点一：[争议描述]
  路径甲：[理由摘要] ——代表案例：（案号）[来源标签]
  路径乙：[理由摘要] ——代表案例：（案号）[来源标签]
  实践建议：优先援引 [高效力位阶路径]，低位阶路径作备位论点。
```

### 3.3 检索空或规则不足时的处理

若高度类似案例为零，本节写明："未检索到足量类案，无法归纳裁判规则；以下为基于法律框架
的推演，标 `[模型知识-未验证]`。"

---

## 第四节：裁判倾向统计

**对应**：`21-case-skeleton.md` 步骤五（裁判倾向统计）。

内容要求：

### 4.1 基础统计表

仅基于**高度类似**样本（N），部分类似仅可附注参考、不计入分母：

| 裁判走向 | 件数 | 占比 |
|----------|------|------|
| 支持主张 | n₁ | n₁/N |
| 不支持主张 | n₂ | n₂/N |
| 部分支持/条件成立 | n₃ | n₃/N |

**样本不足强制披露（N ≤ 5 时必须出现，不得省略）：**

```
⚠️ 样本警示：高度类似案例仅 N 件（N 偏小），以下比例仅供参考，不代表裁判规律，
请主办律师结合实际情况判断，不得单独援引本统计作为结论依据。
```

样本为 0 或极少（仅参考层级案例）时，跳过比例统计，改为条件式结论（"若事实特征 X
成立，则倾向 Y"），并在第五节注明"现有样本量不支持倾向性统计结论"。

### 4.2 关键变量分析（N 足够时展开）

- **法院层级**：最高院/高院/中院/基层院支持率对比（如有差异则说明）。
- **地域**：省市间裁判倾向有无系统分化（如有则给出方向）。
- **时间趋势**：近三/五年走向是否有变化（关联立法修订或新指导性案例）。

若 N 过小无法展开分析，各小节填写"样本量不足，不展开变量分析"，不强行给结论。

### 4.3 统计局限性说明

- 检索工具覆盖度：仅检索到 MCP 可查文书或模型知识回退，存在检索盲区；
- 公开裁判文书的代表性局限：和解/调解案件不在统计内；
- 时效局限：统计截至第一节检索时间戳，此后新发案例不在其中。

---

## 第五节：个案启示

**对应**：`21-case-skeleton.md` 步骤六（个案启示）。

本节遵守执业级写作姿态：直接给结论，不采用学生化占位。

内容要求：

1. **裁判走向预判**：对照用户事实的高权重核心事实与第二节高度类似样本的胜诉/败诉关键
   要素，给出预判（可能性：高/中/低）及核心理由（1–3 条）；样本不足时给条件式预判
   （"若 X 成立，则走向 Y"），不拒绝下结论。
2. **关键变量对照**：用户事实所属法院层级、地域是否落在第四节统计的有利区间；存在
   不利因素时明确提示。
3. **可操作建议**：
   - 证据补强方向（对照第三节规则归纳的胜诉关键要件）；
   - 论点选择（优先援引第三节高效力位阶裁判路径，低位阶作备位论点）；
   - 时效与时机：是否有近期修法或新发指导性案例改变裁判走向，触发
     `10-retrieval-core.md` 的强制复核触发条件时，建议主办律师强制核验。
4. **局限性说明**：若第四节已披露样本不足，此处再次注明"建议补充检索后复核启示"；若
   大量来源为 `[模型知识-未验证]`，明确提示"来源核验不足，启示仅供初步参考"。

---

## 第六节：来源与核验

**对应**：跨步骤汇总——集中呈现全流程（步骤二检索、步骤四归纳及各触发点）产生的核验
状态，格式定义于 `49-citation-disclaimer.md` § 六。本节不在此重抄模板细节，仅列出必含项：

1. **MCP 接入状态**：已接✓ / 未接—引用源于模型知识需核实。
2. **检索时间戳**：YYYY-MM-DD（与第一节一致）。
3. **强制核验事项（如有）**：集中列出全部未能通过外部源核验的高风险命题，格式：
   ```
   ⚠️ 强制核验—尚未经外部源核实：
   - [命题]：引用源于模型知识，请主办律师手动核查。
   ```
4. **来源采信层级说明（如有来源冲突）**：说明冲突及采信决定。
5. **免责声明**：附 `49-citation-disclaimer.md` § 七定义的完整免责声明定稿文本，不删减、
   不改写。

---

## 输出格式与交付规范

- 报告节次顺序固定，不可调换或省略节名（即使某节内容简短，保留节名并简短说明原因，如
  "未检索到类案，本节按第三节 3.3 处理"）。
- 行文风格：执业律师级——结论先行，检索路径精确可复现，不堆列案例原文，不写模糊的
  "需要具体分析"。
- 报告成稿后须先经 `48-qc-gate.md` 七项终检全部通过，方可交付；未通过项按其精确回退
  目标退回对应骨架步骤补正。
- 本报告为内部检索文件；正式对外提交时需主办律师复核，并附
  `49-citation-disclaimer.md` § 七的免责声明。
