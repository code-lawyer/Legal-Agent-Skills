# 九、解除终止(CL-TER)

#### CL-TER-01 委托合同任意解除权及赔偿条款

- 类别:解除终止 | 适用立场:中立
- 问题版:"本合同一经签订,任何一方不得单方解除。"——试图完全排除委托合同双方的法定任意解除权,该等排除条款效力存疑。
- 推荐措辞:委托人和受托人均可以随时解除本合同;因解除本合同给对方造成损失的,除不可归责于解除方的事由外,解除方应当赔偿对方因此受到的损失,具体范围包括:(1)受托人已完成工作量对应的合理报酬;(2)受托人为履行本合同已实际发生且不可挽回的必要费用;(3)因解除给对方造成的其他直接损失。行使解除权的一方应提前______日书面通知对方。
- 法律依据[待查]:委托合同任意解除权及解除后损失赔偿相关规定 [待查]
- 实务提示:试图在合同中完全排除该法定任意解除权的条款效力存疑;起草重点应放在"解除后赔偿范围"的具体化,而非徒劳地排除解除权本身。

#### CL-TER-02 承揽合同定作人任意解除权及赔偿条款

- 类别:解除终止 | 适用立场:乙方(承揽人)
- 问题版:未约定定作人行使任意解除权后的具体赔偿范围,承揽人实际投入缺乏保障。
- 推荐措辞:定作人可以随时解除本承揽合同;定作人行使解除权造成承揽人损失的,应当赔偿承揽人的损失,具体范围包括:(1)承揽人已完成工作部分对应的报酬;(2)承揽人为履行本合同已购置且无法另作他用的材料、设备费用;(3)承揽人可得利益损失(以本合同约定的报酬总额与已完成部分对应报酬的差额为限,并应扣减承揽人因合同解除而减少的相应支出)。定作人应提前______日书面通知承揽人。
- 法律依据[待查]:承揽合同定作人任意解除权及损失赔偿范围相关规定 [待查]
- 实务提示:承揽人一方审查时应重点关注赔偿范围是否覆盖其实际投入及合理可得利益,避免仅约定"已完成部分报酬"而遗漏材料损失、可得利益。

#### CL-TER-03 协议解除条款

- 类别:解除终止 | 适用立场:中立
- 问题版:未约定双方协商一致解除合同的程序与解除后的清算方式。
- 推荐措辞:双方可以协商一致解除本合同。协商解除的,双方应就已履行部分的费用结算、已交付成果/标的物的处理、尚未了结事项的处理方式等,另行签订书面解除协议予以明确;解除协议未就相关事项作出约定的,依本合同原约定的相应条款处理。
- 法律依据[待查]:协议解除相关规定 [待查]
- 实务提示:应避免"口头协商一致即视为解除"的模糊操作,协议解除应落实为书面文件并明确清算安排。

#### CL-TER-04 法定解除情形与程序条款

- 类别:解除终止 | 适用立场:中立
- 问题版:合同未列明具体的法定解除情形,仅笼统表述"一方违约的,对方有权解除合同"。
- 推荐措辞:有下列情形之一的,守约方有权书面通知违约方解除本合同:(1)因不可抗力致使本合同目的不能实现的;(2)违约方迟延履行主要义务,经守约方催告后在合理期限内仍未履行的;(3)违约方迟延履行或者有其他违约行为致使不能实现合同目的的;(4)违约方明确表示或者以自己的行为表明不履行本合同主要义务的;(5)法律规定的其他情形。守约方解除本合同的,应以书面形式通知对方,合同自通知到达对方时解除;对方对解除有异议的,可以请求人民法院或者仲裁机构确认解除行为的效力。
- 法律依据[待查]:法定解除情形及解除通知生效相关规定 [待查]
- 实务提示:应将"致使不能实现合同目的"这一核心判断标准具体化为可操作情形,避免解除权行使时因标准模糊引发对方异议。

#### CL-TER-05 解除后清算条款

- 类别:解除终止 | 适用立场:中立
- 问题版:合同约定了解除情形,但未约定解除后已履行部分如何清算、已支付款项如何处理。
- 推荐措辞:本合同解除后,尚未履行的部分终止履行;已经履行的部分,依履行情况及本合同性质,双方应按下列原则清算:(1)已交付且验收合格的标的物/工作成果,按已交付部分对应的价款/报酬结算,不予返还;(2)已支付但未产生对应交付/工作成果的预付款项,应予退还;(3)因解除给守约方造成的损失,由违约方依本合同违约责任条款承担赔偿责任。双方应在合同解除之日起______日内完成前述清算并书面确认。
- 法律依据[待查]:合同解除后清算及恢复原状相关规定 [待查]
- 实务提示:清算条款应逐项列明各类已发生款项/成果的处理规则,避免解除后"该退的退不了、该结的结不清"。

#### CL-TER-06 经济补偿金(N)计算条款

- 类别:解除终止 | 适用立场:乙方(劳动者)
- 问题版:"用人单位应向劳动者支付经济补偿。"——未明确计算方式与月工资基数认定标准。
- 推荐措辞:用人单位依法应向劳动者支付经济补偿的,按劳动者在本单位的工作年限,每满一年支付一个月工资的标准向劳动者支付;六个月以上不满一年的,按一年计算;不满六个月的,向劳动者支付半个月工资的经济补偿。前述月工资,按劳动者在劳动合同解除或者终止前十二个月的平均工资计算;劳动者月工资高于用人单位所在地上年度职工月平均工资三倍的,按职工月平均工资三倍的数额支付,向其支付经济补偿的年限最高不超过十二年(具体倍数及年限上限须以检索核验后现行有效的规定为准)。
- 法律依据[待查]:经济补偿金(N)计算基数及封顶规则相关规定 [待查]
- 实务提示:封顶规则的具体倍数、年限需检索核验现行有效性后代入;计算基数应以离职前十二个月实际平均工资(含奖金、津贴等工资性收入)认定,不得仅按基本工资计算。

#### CL-TER-07 代通知金(N+1)适用情形条款

- 类别:解除终止 | 适用立场:中立
- 问题版:未区分"未提前通知即解除"与"劳动合同期满劳动者不同意续订"两种情形,混淆代通知金适用条件。
- 推荐措辞:用人单位依据法定客观情况发生重大变化等情形单方解除劳动合同,未提前三十日以书面形式通知劳动者本人的,应当额外向劳动者支付一个月工资作为代通知金,该代通知金与经济补偿(N)合并支付(即N+1)。劳动合同期满,用人单位维持或者提高劳动合同约定条件续订劳动合同,劳动者不同意续订的,用人单位无需支付经济补偿,亦不适用本条代通知金安排,不属于N+1情形。
- 法律依据[待查]:代通知金适用情形及与经济补偿关系相关规定 [待查]
- 实务提示:代通知金的触发条件仅为"用人单位未提前三十日书面通知即解除",与劳动者是否同意续订劳动合同无关,审查时应重点甄别避免两种情形混淆。

#### CL-TER-08 违法解除/终止赔偿金(2N)条款

- 类别:解除终止 | 适用立场:乙方(劳动者)
- 问题版:未约定用人单位违法解除或终止劳动合同的法律后果。
- 推荐措辞:用人单位违反法律规定的条件或者程序解除或者终止本合同的,劳动者要求继续履行本合同的,用人单位应当继续履行;劳动者不要求继续履行或者本合同已经不能继续履行的,用人单位应当依照经济补偿标准的二倍向劳动者支付赔偿金(即2N),不再另行支付经济补偿(N)。
- 法律依据[待查]:违法解除/终止劳动合同赔偿金相关规定 [待查]
- 实务提示:应审查用人单位解除/终止的事由、程序是否符合法定情形(如是否履行了通知工会等程序),事由不成立或程序违法的均可能构成违法解除。

#### CL-TER-09 任意解除权限制与解除后过渡安排条款(长期合作/框架服务类)

- 类别:解除终止 | 适用立场:中立
- 问题版:长期合作的框架服务协议未约定任意解除后的过渡期安排,导致解除后业务交接混乱。
- 推荐措辞:任何一方依法或依约行使解除权的,应提前______日书面通知对方,双方应在通知期内相互配合完成工作交接,包括但不限于资料移交、账户权限清理、客户/供应商通知等必要事项;解除方未按约定提前通知即径行解除的,应赔偿对方因缺乏合理过渡期而扩大的损失。
- 法律依据[待查]:合同解除的过渡期安排及配合义务相关规定 [待查]
- 实务提示:长期外包、框架采购、框架服务类合同尤其需要该条,避免"说解除就解除"导致业务真空期损失扩大。
